# Data

This folder contains the final synthetic Nigerian bank-customer churn dataset used for the TechCrush Cohort 7 Group 9 capstone project.

## Main Dataset

`nigerian_bank_churn_synthetic_v2.csv`

The dataset contains 15,000 synthetic customer records and 48 variables. It was developed strictly for academic and educational machine-learning purposes and does not contain real customer information.

The corresponding data dictionary is available in the `documentation` folder.
