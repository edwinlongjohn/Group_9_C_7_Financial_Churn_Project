# Documentation

This folder contains supporting documentation for the Bank Customer Churn Prediction capstone project.

## Data Dictionary

The main documentation file is:

`bank_churn_design_and_dictionary.xlsx`

It describes the dataset variables, definitions, data types, expected ranges, categories and design assumptions used in developing the synthetic Nigerian bank-customer churn dataset.

The data dictionary should be consulted when validating the dataset, conducting exploratory data analysis, preprocessing variables and interpreting the machine-learning results.
