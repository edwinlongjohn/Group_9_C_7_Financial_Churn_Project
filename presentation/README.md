# Presentation

This folder contains the final presentation materials for the Bank Customer Churn Prediction capstone project.

The presentation will summarise:

- The business problem and project objectives
- The synthetic dataset and its main characteristics
- Data-quality assessment and exploratory analysis
- Data preprocessing and modelling approach
- Model performance and comparison
- Important predictors of customer churn
- Customer-retention recommendations
- Project limitations and conclusion

The final presentation file will be uploaded here after completion.
