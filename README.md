# Bank Customer Churn Prediction Using Machine Learning

## TechCrush Cohort 7 — Group 9 Capstone Project

This project develops a machine-learning model for identifying bank customers who may be at risk of churning within the next six months.

The analysis uses a synthetic Nigerian bank-customer dataset containing demographic, financial, transaction, engagement, service-experience and account-behaviour variables.

## Project Objectives

- Analyse the characteristics and behaviours associated with customer churn.
- Prepare the dataset for machine-learning modelling.
- Train and compare multiple classification models.
- Evaluate model performance using appropriate metrics.
- Identify important predictors of customer churn.
- Provide practical customer-retention recommendations.

## Dataset

The project uses a fully synthetic dataset developed for academic and educational purposes. It does not contain real customer records or personally identifiable banking information.

The final dataset contains approximately:

- 15,000 customer records
- 48 variables
- One target variable: `Churn_Within_6M`

## Planned Models

- Dummy Classifier
- Logistic Regression
- Random Forest
- Gradient Boosting

## Evaluation Metrics

The models will be evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- PR-AUC
- Confusion matrix
