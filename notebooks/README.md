# Notebooks

This folder contains the Jupyter and Google Colab notebook used for the Bank Customer Churn Prediction capstone project.

## Main Notebook

`Bank_Customer_Churn_Final.ipynb`

The notebook contains the complete machine-learning workflow, including:

- Project introduction and objectives
- Dataset loading and validation
- Exploratory data analysis
- Data preprocessing
- Train-test splitting
- Machine-learning model training
- Model evaluation and comparison
- Feature importance and interpretation
- Customer-retention recommendations
- Project limitations and conclusion

The notebook is designed to run from beginning to end and reproduce the final analysis and results.
