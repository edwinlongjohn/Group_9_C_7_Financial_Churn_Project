# Notebooks

This folder contains the Jupyter/Google Colab notebook used for the Bank Customer Churn Prediction capstone project.

## Final Notebook

[`Bank_Customer_Churn_Prediction_Final.ipynb`](Bank_Customer_Churn_Prediction_Final.ipynb)

The notebook contains the complete machine-learning workflow, including:

* Project introduction and objectives
* Dataset loading and validation
* Exploratory data analysis
* Data preprocessing
* Train-test splitting
* Model training and comparison
* Threshold selection
* Final model evaluation
* Feature importance and interpretation
* Customer risk-tier analysis
* Retention recommendations
* Limitations and conclusion
* Model export and verification

The notebook was restarted and executed from beginning to end without errors. Its saved outputs allow the final analysis and results to be reviewed directly on GitHub.
